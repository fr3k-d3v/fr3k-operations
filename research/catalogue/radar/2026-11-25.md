## 1. llama.cpp: batched OpenCL speculative-decoding verification kernels for Adreno

- **Summary:** Qualcomm contributor `lhez` merged OpenCL kernels that verify up to 8 draft tokens in one batched call. The Q4_K version is [PR 32716](https://github.com/ggml-org/llama.cpp/pull/32716) (merged 23 Nov 2026, build b12648 as reported). The Q6_K version is [PR 32909](https://github.com/ggml-org/llama.cpp/pull/32909) (merged 24 Nov 2026, build b12679 as reported).
- **VERIFIED FACT:** both pull requests are merged on the primary repository (merge dates re-read from the GitHub API on 28 Nov 2026; build numbers are as reported on the day and were not re-checked).
- **CLAIM (author figures, not reproduced):** decode 27.16 → 32.29 tokens/s in PR 32716, and 32.09 → 33.10 tokens/s in PR 32909, both on gemma-4-E4B with a 32k-token prompt. Acceptance rates differ between the two runs, so these are not clean before-and-after tests.
- **UNKNOWN:** whether the Q4_K kernel is enabled for the Adreno 840 in the REDMAGIC 11S Pro. The commit enables it explicitly for Snapdragon X2.
- **Reproduced:** no.
- **Why it matters for FR3K:** it runs over the OpenCL path that already passed a basic check on the REDMAGIC 11S Pro (see [EXP-2026-001](../experiments/EXP-2026-001-npu-runtime-bakeoff.md)), so it is a cheap add-on to the bake-off.
- **Next action:** [EXP-2026-009](../experiments/EXP-2026-009-opencl-spec-decode-adreno.md).

## 2. llama.cpp: `llama-quantize --target-size` and `--target-bpw`

- **Summary:** new options pick a quantisation type per tensor so the model meets a size or bits-per-weight budget at the lowest estimated error. [PR 15550](https://github.com/ggml-org/llama.cpp/pull/15550) (author `EAddario`) merged 3:06am on 24 Nov 2026 (Brisbane; 23 Nov 17:06 UTC) and shipped in [b12669](https://github.com/ggml-org/llama.cpp/releases/tag/b12669).
- **VERIFIED FACT:** the pull request is merged.
- **CLAIM (author, not reproduced):** the result matched or beat the standard quants on quality in 93% of 238 tests.
- **Reproduced:** no.
- **Why it matters for FR3K:** it allows a model to be fitted exactly to a RAM budget on the REDMAGIC 11S Pro or an older handset.
- **Next action:** [EXP-2026-011](../experiments/EXP-2026-011-quantize-target-size-fit.md).

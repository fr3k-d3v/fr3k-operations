# Commercial and contracting model (AUD)
Status: DRAFT pricing hypothesis, not an offer, accepted quote or guarantee. Tax/GST treatment to be confirmed by accountant. No invoice or purchase order issued.

## Target package
A$50,000 base implementation target: A$20,000 initial milestone and A$30,000 on accepted delivery. Higher delivery fee only by signed change order or separately priced phase. Specify whether figures include GST, travel, licences, hosting, hardware freight and support.

### Proposed A$20,000 initiation milestone
- Hardware allowance A$5,000–10,500 subject to selected platform, supplier quote, shipping and availability; **do not buy before signed contract**.
- Discovery, workflow mapping, privacy/security assessment and acceptance specification.
- Architecture, initial synthetic demo, deployment plan and reserved engineering capacity.
- Contract must allocate hardware title, warranty, substitution rights, cancellation, refund treatment and procurement lead times; payment due on agreed commencement deliverables, not an unearned non-refundable deposit.

### Proposed A$30,000 acceptance milestone
- Versioned tenant-configured platform, crew/event workflow, approved adapters, tested appliance, training, documentation, backup/restore evidence, user acceptance signoff and handover.
- Payment triggered by objective acceptance tests and remediation window, not vague 'AI complete'.
- No production payroll or legal advice in base scope; adapters and integrations contingent on API access and client licences.

## Example internal cost scenario (not supplier quotes)

These examples show why price cannot be justified by hardware alone. Track actual effort and margin before commitment.

## Commercial alternatives
- A$50k fixed-scope base; options priced separately: EOR automation, client portal, multi-site production control, advanced AI voice assistant, reporting, integrations.
- Ongoing support/security updates: propose A$1,000–3,000/month depending on SLA, support hours, third-party costs and obligations; no arbitrary guaranteed savings.
- Optional pilot-only agreement before full contract, credited against implementation by written agreement.
- Licensing: FR3K core remains vendor-owned/open-source per Apache-2.0, custom deliverables and data ownership explicitly specified. Client retains ownership/control of business data and exports. Define source-code escrow or continuity path if requested.

## Acceptance and governance
Written scope, change control, integration prerequisites, hardware specification, warranty, uptime targets, disaster recovery, incident response, service boundaries, data processing, privacy, accessibility, offboarding and exit exports. Explicit independent verification for payroll/award calculations. No self-certified compliance claims.

## ROI worksheet
Observed shifts × verified admin minutes saved/shift × fully loaded admin hourly rate / 60. Subtract new support, review, error-handling and licensing costs. Model conservative/base/optimistic cases; never treat 4,000 historic shifts as a forecast.
